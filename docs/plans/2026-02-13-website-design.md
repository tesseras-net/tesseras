# Website Design — tesseras.net

**Date:** 2026-02-13
**Status:** Approved

## Overview

Project website for Tesseras — a static site built with Zola, self-hosted, serving as the public face of the project. Inspired by kernel.org: functional, text-centric, no JavaScript, fast rendering.

## Decisions

| Decision | Choice | Why |
|----------|--------|-----|
| Static site generator | Zola | Rust-native, single binary, built-in i18n & Atom feeds |
| Hosting | Self-hosted | On existing infrastructure (Hetzner/DO) |
| Domain | tesseras.net | .net fits a network project |
| Color scheme | Warm monochrome | Off-white/cream + soft black, timeless feel |
| Typography | System font stack | No web font downloads, fast rendering |
| JavaScript | None | Zero JS, pure HTML + CSS |
| Languages | English + Brazilian Portuguese | English default, pt-br as second language |
| Branding | Text-only wordmark | "Tesseras" in text, no logo/icon for now |

## Layout

Single-column centered layout, `max-width: 42em` (~672px). Generous vertical padding.

### Navigation

Horizontal text links at the top, below the wordmark:

```
Tesseras

About | News | Releases | FAQ | Subscriptions | Contact
English | Português
```

### Footer

Minimal: copyright, Atom feed links, source repository link.

- System font stack (no web fonts)

- Headings: same family, heavier weight

## Pages

### Homepage (About)

The landing page. Short and direct:

- **Opening statement** — one sentence: what Tesseras is
- **Why it exists** — 2-3 sentences on the problem (memories lost to platform shutdowns, format rot, company failures)
- **How it works** — brief bullets: P2P, erasure coding, no company dependency, open source
- **Current status** — which phase the project is in, link to releases
- **Get involved** — links to mailing list, source code, contact

### News

Blog-style section. Each post is a dated Markdown file. News page lists posts in reverse chronological order (title, date, 1-line summary). Atom feed auto-generated by Zola.

### Releases

Table format (like kernel.org):

| Version | Date | Tarball | Signature | Changelog |

Until actual releases exist, explains the release format (signify-signed tarballs, BLAKE3 checksums, semantic versioning) and states "No releases yet."

### FAQ

Derived from the roadmap and typical P2P project questions:

- What is a tessera?
- How does my data survive if my computer dies?
- Is my data encrypted?
- Do I need to pay anything?
- What platforms does it run on?
- How is this different from IPFS/Filecoin/Arweave?

### Subscriptions

Mailing list signup page. Explains the project mailing list with signup instructions.

### Contact

Project maintainer info, mailing list link, source repository links (SourceHut + GitHub mirror).

### Extra Resources (footer or Contact page)

- Book: link to mdBook (when it exists)
- Social: project social accounts
- Mailing list archives

## Atom Feeds

- News: `tesseras.net/news/atom.xml`
- Releases: to be added when releases exist

## i18n

- Zola built-in multilingual support
- `default_language = "en"`
- Portuguese at URL prefix: `/pt-br/about/`
- `<link rel="alternate" hreflang="...">` tags on every page
- Language switcher in header

## SEO

- Semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`)
- `<meta>` description per page
- `hreflang` alternates for all pages
- Clean URLs
- Fast: single CSS file, no JS, no fonts
